# Portfolio CV - Đỗ Trí Đạt

Trang portfolio cá nhân giới thiệu thông tin, kỹ năng, hình ảnh và một số nội dung dự án của Đỗ Trí Đạt. Giao diện được xây dựng bằng HTML5 và CSS3, hỗ trợ nhiều kích thước màn hình.

## Nội dung

- Giới thiệu cá nhân
- Danh sách kỹ năng
- Các thẻ dự án và hình ảnh
- Thông tin liên hệ
- Khung nhập ý kiến phản hồi (chỉ là giao diện, chưa gửi hoặc lưu dữ liệu)

## Công nghệ

- HTML5
- CSS3: Flexbox, Grid và media queries

## Xem trang

Không cần cài đặt thư viện hay chạy bước build. Mở `index.html` bằng trình duyệt để xem trang.

## Cấu trúc thư mục

```text
.
├── index.html
├── README.md
├── assets/
│   ├── css/
│   │   └── styles.css
│   └── img/
└── docs/
    └── RELEASENOTE.md
```

## Tùy chỉnh

- Chỉnh nội dung các phần trong `index.html`.
- Chỉnh màu sắc, bố cục và hiệu ứng trong `assets/css/styles.css`.
- Thay ảnh trong `assets/img/` và cập nhật đường dẫn ảnh tương ứng trong `index.html`.
